# Luis Barber - Barbería Premium

## Español

### Descripción
Sitio web para **Luis Barber**, una barbería premium ubicada en Jiutepec, Morelos. El sitio incluye información sobre servicios, precios, galería de estilos, sistema de agendamiento de citas y contacto por WhatsApp.

### Características
- Diseño responsive (móvil, tablet, desktop)
- Modo claro y oscuro
- Sistema de agendamiento de citas con WhatsApp
- Galería de estilos
- Animaciones suaves
- Interfaz moderna y elegante

### Tecnologías
- **HTML5** - Estructura semántica
- **CSS3** - Estilos personalizados con animaciones
- **JavaScript** - Funcionalidad interactiva
- **Tailwind CSS** - Framework utility-first
- **Remix Icon** - Iconografía
- **Google Fonts** - Tipografías premium

### Estructura del Proyecto
```
barberia/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos personalizados
├── js/
│   └── main.js         # Funcionalidad JavaScript
├── media/              # Imágenes del sitio
│   ├── foto1.webp
│   ├── corte_clasico.webp
│   ├── corte_fade.webp
│   ├── corte_regular.webp
│   ├── corte_barba.webp
│   └── corte_cejas.webp
├── .gitignore          # Archivos ignorados por Git
└── README.md           # Este archivo
```

### Instalación
1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/luis-barber.git
   ```
2. Abre `index.html` en tu navegador
